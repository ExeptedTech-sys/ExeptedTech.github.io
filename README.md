# ExeptedTech · Luvia Company

Sitio estático listo para GitHub Pages.

## Publicar

1. Descomprime el ZIP.
2. Sube **el contenido de esta carpeta** a la raíz de tu repositorio de GitHub.
3. En GitHub abre `Settings → Pages`.
4. Selecciona `Deploy from a branch`, rama `main` y carpeta `/ (root)`.
5. Conserva el archivo `CNAME` para usar `exeptedtech.xyz`.

## Importante

- El número de WhatsApp está configurado en `app.js` como `525566147938`.
- Las cuentas mostradas son una demostración local. Un registro real requiere Firebase, Supabase u otro backend seguro.
