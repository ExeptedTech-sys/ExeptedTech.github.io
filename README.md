# ExeptedTech · Página pública

Esta carpeta contiene los archivos estáticos para publicar en GitHub Pages con el dominio `exeptedtech.xyz`.

**Atención:** Las cuentas están en modo de preparación (`registrationEnabled: false` en `config.js`); esto NO significa que la verificación por correo ya se haya probado en producción. No coloques secretos SMTP, API Resend, `service_role` ni la clave secreta de Cloudflare en GitHub.

Para configurar el backend y habilitar los registros, utiliza el documento entregado por separado `CONFIGURACION_SUPABASE/PASOS_ANTES_DE_ACTIVAR_CUENTAS.md`.
